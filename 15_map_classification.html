Transit shares by census tract, as in deck 14

library(tidyverse)
library(tmap)
library(cancensus)

ct <- get_census(
  dataset = "CA21", regions = list(CMA = "59933"), level = "CT",
  vectors = c(total = "v_CA21_7632", transit = "v_CA21_7644"),
  geo_format = "sf"
) |>
  mutate(transit_pct = 100 * transit / total)

transit_pct is the share of commuters in each census tract who travel mainly by public transit.

A continuous scale makes areas hard to compare

tm_shape(ct) +
  tm_polygons(fill = "transit_pct", col = NULL,
              fill.scale = tm_scale_continuous(values = "brewer.blues"),
              fill.legend = tm_legend(title = "Transit share (%)"))

Classes group similar values

tm_shape(ct) +
  tm_polygons(
    fill = "transit_pct", col = NULL,
    fill.scale = tm_scale_intervals(style = "jenks", n = 5,
                                    values = "brewer.blues"),
    fill.legend = tm_legend(title = "Transit share (%)"))

The break method changes the story

Three common break methods

style = How it sets breaks Watch out for
"equal" Classes of equal width With skewed data, most areas land in the lowest classes.
"quantile" The same number of areas in each class Small differences can look large.
"jenks" Natural gaps in the data Breaks are hard to compare across maps.

Look at the distribution before choosing

ggplot(ct, aes(transit_pct)) +
  geom_histogram(bins = 40) +
  labs(x = "Public transit share (%)", y = "Census tracts")

Match the palette to the data

  • Sequential for low-to-high values: "brewer.blues", "brewer.yl_or_br".
  • Diverging for values above and below a midpoint: "brewer.rd_bu".
  • Categorical for groups with no order: "brewer.set2".

Browse palettes at https://colorbrewer2.org.

How far is each tract from the CMA average?

cma_avg <- 100 * sum(ct$transit, na.rm = TRUE) / sum(ct$total, na.rm = TRUE)
cma_avg
[1] 14.92634
ct <- ct |> mutate(diff = transit_pct - cma_avg)

cma_avg divides all transit commuters by all commuters, so tracts with more commuters count more. It is not the same as mean(ct$transit_pct).

A diverging palette shows above and below average

tm_shape(ct) +
  tm_polygons(
    fill = "diff", col = NULL,
    fill.scale = tm_scale_intervals(breaks = c(-15, -10, -5, 0, 5, 10, 35),
                                    values = "brewer.rd_bu", midpoint = 0),
    fill.legend = tm_legend(title = "Points above CMA average"))

Large areas dominate the eye

  • The biggest tracts in the last map are rural, with few commuters.
  • Readers see area, not population.

Before you draw conclusions, check how many people live in the areas that catch your eye.

Format legend labels

tm_shape(ct) +
  tm_polygons(
    fill = "transit_pct", col = NULL,
    fill.scale = tm_scale_intervals(
      style = "jenks", n = 5, values = "brewer.blues",
      label.format = tm_label_format(suffix = "%", digits = 0),
      value.na = "grey80", label.na = "No data"),
    fill.legend = tm_legend(title = "Public transit share"))

Avoid tm_label_format(fun = ...) for interval scales: in tmap 4.4.1 it printed a message and then hung during testing. Use suffix, prefix, and digits instead.
