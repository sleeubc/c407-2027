A tibble is a set of equal-length columns

library(tidyverse)
bca <- read_rds("data/bca262.rds")

bca |>
  select(sale_date, aa_label, floorarea, price) |>
  head(4)
# A tibble: 4 × 4
  sale_date  aa_label          floorarea  price
  <date>     <chr>                 <dbl>  <dbl>
1 2000-01-01 Surrey-White Rock      1629 211000
2 2000-01-01 Vancouver              2969 775000
3 2000-01-01 Vancouver              1252 340000
4 2000-01-01 Vancouver               960 210000

Each column is a vector. Every column has the same number of values.

A vector holds values of one type

a <- c(0, 1, 2)
b <- c("A", "B", "C")
class(a)
[1] "numeric"
class(b)
[1] "character"

c() combines values into a vector.

Quick check: what type is this vector?

x <- c("0", "1", "2")

A. numeric B. character

x <- c("0", "1", "2")
class(x)
[1] "character"

The quotation marks make each value text.

The type decides what you can do

a * a
[1] 0 1 4
b * b
Error in `b * b`:
! non-numeric argument to binary operator

Arithmetic works on numbers, not text.

A comparison returns a logical vector

price <- c(450000, 1200000, 800000)
price > 1000000
[1] FALSE  TRUE FALSE
class(price > 1000000)
[1] "logical"

TRUE and FALSE are logical values, the third type after numeric and character.

Compare with >, <, >=, <=, == (equal), and != (not equal). A single = does not compare.

TRUE counts as 1

sum(price > 1000000)
[1] 1
mean(price > 1000000)
[1] 0.3333333

sum() counts the TRUE values, and mean() gives their share.

To find what share of sales meet a condition, take the mean() of the condition.

[ ] picks elements by position

price[2]
[1] 1200000
price[c(1, 3)]
[1] 450000 800000
price[-1]
[1] 1200000  800000

Positions start at 1. A minus sign drops an element.

[ ] with a logical vector keeps the TRUEs

price[c(FALSE, TRUE, FALSE)]
[1] 1200000
price > 1000000
[1] FALSE  TRUE FALSE
price[price > 1000000]
[1] 1200000

Each TRUE keeps the element in that position. The comparison builds the TRUE/FALSE vector for you.

filter() in the next deck does the same to the rows of a tibble: it keeps the rows where the condition is TRUE.

A comparison with NA gives NA

price2 <- c(450000, NA, 800000)
price2 > 500000
[1] FALSE    NA  TRUE
sum(price2 > 500000)
[1] NA
sum(price2 > 500000, na.rm = TRUE)
[1] 1

R cannot tell whether a missing price is above 500,000, so the answer is NA.

na.rm = TRUE drops the missing values. Count them first with sum(is.na(price2)).

Create a tibble with tibble()

tb <- tibble(a = c(0, 1, 2), b = c("A", "B", "C"))
tb
# A tibble: 3 × 2
      a b    
  <dbl> <chr>
1     0 A    
2     1 B    
3     2 C

Functions for looking at a tibble

Function Returns
tb$a Column a as a vector
class(tb$a) The type of column a
names(tb) Column names
nrow(tb) Number of rows
head(tb, 2) First two rows (six by default)
summary(tb) A summary of each column
glimpse(tb) Names, types, and first values of every column
View(tb) Nothing: opens the data in the Data Explorer (Console only)

View() opens the data in the Data Explorer

Run this in the Console, not in your document:

View(bca)
  • Scroll through the rows, sort by a column, and add filters.
  • The summary panel shows each column’s type and missing values.
  • Note the capital V. With the tidyverse loaded, view() also works.

Sorting or filtering in the Data Explorer does not change bca. Use code for anything your analysis needs.

Try it: sort bca by price. What kind of property sold for the most?

  • Answer: a “Strata-Lot Residence (Condominium)” property in City of Vancouver, $53,650,000, sold on 20 May 2013. A single sale like this pulls up an average: look before you summarise.
  • View() and view() do nothing when the document renders, so keep them in the Console.
  • The Variables pane also opens the Data Explorer: click the table icon next to bca.
