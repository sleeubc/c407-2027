Maps with tmap

COMM 407 · Static maps, interactive maps, geocoding, and spatial joins

One package for static and interactive maps

  • tmap draws sf objects: polygons, lines, and points.
  • The same code makes a static map for a PDF or slides, or an interactive map for exploring.
library(tmap)

We use tmap version 4. AI tools often write the older version 3 syntax. A translation table comes after the geocoding slides.

Census tracts with geometry

library(tidyverse)
library(sf)
library(cancensus)

ct <- get_census(
  dataset = "CA21", regions = list(CMA = "59933"), level = "CT",
  vectors = c(total = "v_CA21_7632", transit = "v_CA21_7644"),
  geo_format = "sf"
) |>
  mutate(transit_pct = 100 * transit / total)
  • geo_format = "sf" returns tract boundaries with the data.
  • total is all commuters; transit is those who commute mainly by public transit.

The 2021 Census was taken in May 2021, during the pandemic, so transit shares are lower than in 2016. Worth asking students why the census year matters here.

A map starts with tm_shape()

tm_shape(ct) +
  tm_polygons()

Map a variable with fill =

tm_shape(ct) +
  tm_polygons(fill = "transit_pct")

Add a legend title and lighter borders

tm_shape(ct) +
  tm_polygons(fill = "transit_pct",
              fill.legend = tm_legend(title = "Public transit share (%)"),
              col = "white", lwd = 0.2)

Layers stack, as in ggplot

burnaby <- ct |> filter(CSD_UID == "5915025")  # Burnaby's CSD code
parks <- st_read("data/Park_Inventory.geojson", quiet = TRUE)

tm_shape(burnaby) + tm_polygons(fill = "transit_pct") +
  tm_shape(parks) + tm_polygons(fill = "darkgreen", col = NULL)

A basemap adds context

tm_basemap("Esri.WorldGrayCanvas") +
  tm_shape(burnaby) +
  tm_polygons(fill = "transit_pct", fill_alpha = 0.7)

Basemaps download map tiles, so you need internet access. "Esri.WorldGrayCanvas" and "OpenStreetMap" need no API key; CartoDB tiles now do.

View mode makes the map interactive

tmap_mode("view")
tm_shape(burnaby) + tm_polygons(fill = "transit_pct", fill_alpha = 0.7)

Use view mode to check your work

  • Zoom in and click a tract to see its values.
  • This is a quick way to check a join or a calculation: does this tract have the value you expected?
  • Switch back with tmap_mode("plot") before you render to PDF. Interactive maps cannot go in a PDF.

Save a map as a PNG

m <- tm_shape(ct) +
  tm_polygons(fill = "transit_pct",
              fill.legend = tm_legend(title = "Public transit share (%)"))

tmap_save(m, "temp/transit_share.png", width = 8, height = 6, dpi = 300)

Save the map in an object first, then pass it to tmap_save().

Geocoding turns addresses into coordinates

library(tidygeocoder)

places <- tibble(address = c("2053 Main Mall, Vancouver, BC",
                             "999 Canada Place, Vancouver, BC",
                             "800 Robson St, Vancouver, BC")) |>
  geocode(address, method = "arcgis", full_results = TRUE)

places |> select(address, lat, long, arcgis_address, score)
# A tibble: 3 × 5
  address                           lat  long arcgis_address               score
  <chr>                           <dbl> <dbl> <chr>                        <int>

2 999 Canada Place, Vancouver, BC  49.3 -123. 999 Canada Pl, Vancouver, B…   100

Turn coordinates into points on a map

places_sf <- st_as_sf(places, coords = c("long", "lat"), crs = 4326)

# Show 1.5 km around the points, so they are not on the edge of the map
area <- st_bbox(st_buffer(places_sf, 1500))

tm_basemap("OpenStreetMap") +
  tm_shape(places_sf, bbox = area) + tm_dots(fill = "red", size = 1)

A perfect score can be the wrong place

tibble(address = c("1000 Main St", "1000 Main St, Vancouver, BC")) |>
  geocode(address, method = "arcgis", full_results = TRUE) |>
  select(address, lat, long, city = attributes.City, score)
# A tibble: 2 × 5
  address                       lat   long city      score
  <chr>                       <dbl>  <dbl> <chr>     <int>
1 1000 Main St                 32.8  -96.8 Dallas      100
2 1000 Main St, Vancouver, BC  49.3 -123.  Vancouver   100

Without a city, “1000 Main St” matched Dallas, Texas, with a score of 100. Always include the city and province, then map the points.

Google is more precise but needs a key

  • method = "google" reads GOOGLEGEOCODE_API_KEY from .Renviron.
  • You need a Google Cloud account with billing turned on.
  • Restrict the key to the Geocoding API and set a budget alert.
  • Comparing two methods is a good check: look into any address where they disagree.

Spatial joins

Areas, stations, and sales, as in deck 08

library(VancouvR)

local_areas <- get_cov_data("local-area-boundary")
stations <- get_cov_data("rapid-transit-stations")

bca <- read_rds("data/bca262.rds")
sales <- bca |>
  filter(juris_label == "City of Vancouver", year(sale_date) == 2025,
         !is.na(lon), !is.na(lat)) |>
  select(folioid, act_use_cat, price, floorarea, lon, lat) |>
  st_as_sf(coords = c("lon", "lat"), crs = 4326)

local_areas holds the City’s 22 local areas, stations its SkyTrain stations, and sales its 2025 sales as points.

st_join() attaches the area each point falls in

sales_area <- st_join(sales, local_areas)
c(before = nrow(sales), after = nrow(sales_area))
before  after 
  7662   7662 
sales_area |> st_drop_geometry() |> count(name, sort = TRUE) |> head(4)
# A tibble: 4 × 2
  name               n
  <chr>          <int>
1 Downtown        1381
2 Kitsilano        611
3 Mount Pleasant   573
4 West End         527

Each sale gets the name of its local area. Both layers must use the same CRS.

Join the other way to map each area

strata <- sales |>
  filter(act_use_cat == "Strata Res")

strata_by_area <-
  st_join(local_areas, strata) |>
  group_by(name) |>
  summarise(sales = n(),
            median_price = median(price))

tm_shape(strata_by_area) +
  tm_polygons(fill = "median_price")

Each area matches many sales. summarise() merges each area’s rows back into one polygon.

  • st_join(local_areas, strata) keeps an area with no strata sale as one row with NA columns, so n() would report 1 sale there. In 2025 every area has at least 13 strata sales. If that could happen, count sum(!is.na(price)) instead.
  • Strata only, because the mix of houses and strata differs by area (deck 05).

Same name, different boundaries

kerr17 <- bca |>

Deck 06’s kerr17 uses BC Assessment’s Kerrisdale. Only 86 of its 208 sales are in the City’s Kerrisdale. Match areas by location, not by name.

Distance and buffers

Measure distance in metres

sales_m <- st_transform(sales, 26910)
stations_m <- st_transform(stations, 26910)

nearest <- st_nearest_feature(sales_m, stations_m)
dist <- st_distance(sales_m, stations_m[nearest, ], by_element = TRUE)

sales_m <- sales_m |>
  mutate(station = stations_m$station[nearest], dist_m = as.numeric(dist))
sales_m |> st_drop_geometry() |> select(price, station, dist_m) |> head(3)
# A tibble: 3 × 3
    price station               dist_m
    <dbl> <chr>                  <dbl>
1  895000 Broadway - City Hall   1274.
2 1569000 VCC - Clark            1224.
3  575000 Yaletown - Roundhouse  4752.

st_nearest_feature() finds the row of the closest station; st_distance() measures the distance to it. In EPSG 26910 (deck 08), the answer is in metres.

  • With longitude and latitude, sf also measures in metres on a sphere (the s2 engine), but buffers are approximate: a 500 m buffer came out 1.5% too large in area.
  • AI code often calls sf_use_s2(FALSE) to silence a geometry error. Then st_buffer(x, 500) on longitude and latitude draws circles 500 degrees wide. Transforming to metres first avoids both problems.

Strata prices and distance to SkyTrain

strata_m <- sales_m |> filter(act_use_cat == "Strata Res", !is.na(floorarea))

ggplot() +
  geom_point(aes(dist_m, price / floorarea), alpha = 0.2, data = strata_m)

Median price per square foot: $1,093 within 500 m of a station, $1,072 farther away. A vertical stripe is many sales at one distance, such as units in one building.

  • Stations cluster Downtown and along a few corridors, so near and far sales differ in more than distance: age, size, views, and neighbourhood. Deck 18 asks why a raw comparison like this can mislead, and deck 17’s fixed effects compare like with like.

A buffer covers everything within a distance

buffers <- st_buffer(stations_m, 500)

tm_shape(local_areas) + tm_polygons(fill = "grey95") +
  tm_shape(buffers) + tm_polygons(fill = "steelblue", fill_alpha = 0.4)

st_buffer(500) draws a 500-unit circle around each station. In EPSG 26910, that is 500 metres.

Overlapping buffers duplicate rows

sales_near <- st_join(sales_m, buffers)
c(before = nrow(sales_m), after = nrow(sales_near))
before  after 
  7662   8127

A sale within 500 m of two stations matches both, so it appears twice. Counts per station are right, but totals and averages across sales count those sales twice.

After every spatial join, compare the row counts and map the result.

Practice: sales in the floodplain

How many 2025 sales in the City of Vancouver were of homes in the designated floodplain?

  1. Download designated-floodplain with get_cov_data().
  2. Join sales to it, keeping only the sales inside: st_join(sales, floodplain, left = FALSE).
  3. Check the row count. Does each sale appear once?
  4. Map the floodplain and the sales in it.

Answer

floodplain <- get_cov_data("designated-floodplain")

in_flood <- st_join(sales, floodplain, left = FALSE)
nrow(in_flood)
[1] 445
in_flood |> st_drop_geometry() |> count(name)
# A tibble: 3 × 2
  name                                 n
  <chr>                            <int>
1 Designated Floodplain (FCL 4.6m)   412
2 Fraser Risk Today 1/500 Storm       32
3 Still Creek Floodplain               1
nrow(st_filter(sales, floodplain))
[1] 413

The floodplain layers overlap, so 32 sales matched two of them. st_filter() keeps each sale once: 413 sales.

Answer: the map

tm_shape(local_areas) + tm_polygons(fill = "grey95") +
  tm_shape(floodplain) + tm_polygons(fill = "steelblue", fill_alpha = 0.4) +
  tm_shape(st_filter(sales, floodplain)) + tm_dots(size = 0.15)

What to know from this deck

Know
Write it without help

  • tm_shape() + tm_polygons(fill = ), with more layers on top
  • st_join(), then compare row counts

Recognize
Say what the line does

  • get_census(geo_format = "sf")
  • tm_basemap(), tmap_mode("view"), tmap_save()
  • geocode(method = "arcgis", full_results = TRUE)
  • st_buffer(), st_distance(), st_nearest_feature()
  • st_filter(): keep the points inside, once each

Look up
When you meet it

  • fill.legend = tm_legend()
  • Basemap providers
  • tmap v3 and v4 names
  • left = FALSE
  • by_element = TRUE
